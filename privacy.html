Summary

What data is processed

Visiting the website

When you open the site, your browser connects to the web server(s) for the pages and for the game server (API). The web server (nginx) and the game server write technical logs:

  • Game server log: one line per request with method, path (without query string), response status, duration, your IP address, time and a request id. Request headers, bodies, passwords and tokens are not logged.
  • Web server access log: [DESCRIBE THE WEB SERVER ACCESS LOG CONFIGURATION, e.g. "IP address, time, requested URL, status, referrer and user agent" for the nginx default format, or "disabled"].

Your account

When you create an account, the following is stored:

  • username, email address and display name,
  • Discord handle (required) and Telegram handle (optional),
  • your password as a one-way hash (the password itself is never stored),
  • creation and last-change timestamps, account status flags.

The game does not send emails. The email address [STATE WHAT THE EMAIL, DISCORD AND TELEGRAM HANDLES ARE USED FOR, e.g. "to identify you and to contact you about your account or prizes"].

Sign-in sessions

Each sign-in creates a session that is valid for 24 hours. For each session the server stores a random session token, creation and expiry time, your IP address and your browser's user agent.

Security log

Registration, sign-in, sign-out, password changes and account deletion are recorded in a security log with the event type, success or failure (and a short reason such as "invalid credentials"), time, IP address and user agent. Failed attempts that cannot be matched to an account are logged without an account reference.

Gameplay and results

  • When you join a round, a player entry is created with your player name (your display name), a link to your account, the time you joined and your game state (balances, upgrades, trades, scores).
  • When a round ends, the final standings (player name, rank, score, scoring mode, round type, number of participants and finish time) are copied into a results archive. You see them under My results.

Chat

If chat is enabled for a round, your messages are delivered to the players currently connected to the same round, together with your player name and the time. Chat messages are held in memory only for delivery; they are not written to the database or to the logs and there is no chat history.

Backups

The game database is backed up nightly. Backups contain all data described above and are kept for 14 days on the server [ADD OFF-SERVER BACKUP LOCATION AND RETENTION, IF ANY]. Data you deleted can therefore remain in backups until they expire.

Browser storage and cookies

The game uses your browser's local storage (keys beginning with mining-tycoon:) only for things it needs to work:

  • your sign-in token, username and display name,
  • the game server address,
  • the round and player you are in, and a per-round player token so you can rejoin,
  • a snapshot of your last finished round (shown under Last Game Highscores),
  • interface preferences and a cache of game settings (cache entries expire after 7 days).

On sign-in the game server also sets one cookie, app-auth-session (HttpOnly, SameSite=Strict, valid for 24 hours), which holds your session token. It is technically necessary and is removed when you sign out.

No analytics, advertising or tracking cookies or similar technologies are used, so no consent banner is shown. Signing out clears the sign-in entries; you can remove everything at any time through your browser settings.

Third-party content

All fonts, scripts and styles are served from this website itself; the pages do not load anything from Google Fonts or other external content delivery networks.

No third-party content, scripts or trackers are embedded.
